OrbitForge modifications: standard-library C++ types; explicit SI/model inputs;
per-evaluation local scratch arrays; no file lookup/global mutable atmosphere
state; bounded Newton iterations; continuous Jacchia-Roberts angular/equinox
limits; explicit validation and supported domains. Fitted coefficients are
unchanged. The API adapter uses exact WGS84 geodetic height, manual constant
space-weather inputs, and the effective drag density including anomalous oxygen.
