# 中心引力空间偏导

`GravityModel::differential(position_m, degree, order, corrections, secular_at, checkpoint)` 在固定历元返回加速度和 `position_jacobian_per_s2[i][j] = ∂a_i/∂r_j`。输入位置为米，两个输出分别为 m/s² 和 s⁻²；全部使用同一地心地固轴。Jacobian 是引力势的 Hessian，包含单极项，矩阵行是加速度分量、列是位置分量。

这是协方差变分方程的基础。它尚未接入 HPOP 的完整协方差传播，不提供可启用的桌面协方差开关，也没有新增 Python 协方差 API。公开 C++ 头文件随 SDK 安装，消费端验证实际链接和调用。现有 Python 传播接口继续使用原名义加速度。

## 范围与输入

- 支持点质量 0×0、2 至 2190 阶以及文件允许的独立次数，包含 EGM2008 的 2190×2159 矩形范围；拒绝 1 阶、负值和超出文件范围的请求。
- 加性归一化系数沿用已有固体潮／海潮输入契约，可扩展到底场阶次之外，但不能超过计算上限；系数重复或非有限时失败。
- 长期变化沿用文件显式历元和按儒略年的变化率。空间求导时固定力历元及全部系数，不把系数的时间变化混入空间 Hessian。
- 精确南北极和极轴附近均可求值，不需要人为偏移位置或改变纬度。
- 无效位置和不可表示的结果明确失败。可选 `checkpoint` 在开始、每 4096 个实际遍历的系数及一般球谐求值结束时调用；其异常向上传播。模型及系数保持不可变，可跨线程、历元并发调用。

## 解析递推

沿用名义场的无经度除法 Cartesian 角向球谐递推，将二阶 Jet 的六个独立分量 `xx,xy,xz,yy,yz,zz` 与值、一阶导数同时推进。普通 `acceleration()` 使用独立的编译期分支，不计算二阶导数。

令单位位置为 `d = r / |r|`，角向调和项为 `Y_nm(d)`，`k = n+1`，径向权重为 `W_n ∝ |r|^(-k)`。每一项对 Hessian 的贡献为：

```text
H_ij = W_n [∂ij Y_nm − k/|r| (d_i ∂j Y_nm + d_j ∂i Y_nm)
            + k/|r|² ((k+2) d_i d_j − δij) Y_nm]
```

归一化、奇偶性、径向指数权重及最终 μ/R 因子与加速度路径相同。各分量使用补偿求和。高阶极区的 Hessian 按阶数近似二次增长；直接相减两个已舍入的连续 Hessian 会积累误差。因此在既有极区分支直接递推 Hessian 的一阶差分，再补偿累加。此处理只作用于二阶导数，保留原加速度的运算顺序。

Jacobian 只计算上三角并镜像，保证返回值严格对称；没有强制改写对角线来满足零迹。拉普拉斯迹作为独立检验，允许暴露递推误差。

## 后续变分方程接入

[STK Covariance](https://help.agi.com/stk/Content/hpop/hpop-covariance.htm) 的 Gravity Degree/Order 仅控制协方差方程的截断。后续总力偏导装配须单独使用这个截断，保留名义轨迹的原阶次，并将地固 Hessian 以 `Rᵀ H R` 变换回积分惯性系。第三体、阻力、SRP 与相对论的状态偏导、参数敏感度及事件跳变仍须逐项接入，不能仅靠中心引力 Hessian 声称完成协方差。

数值参考、容限和复现方法见[引力空间偏导验证](../validation/gravity_differential_protocol.md)。
