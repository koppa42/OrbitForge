# HPOP 时间正则化

HPOP 通过 C++ `HpopOptions`、Python `HpopSettings` / `Hpop()` 与桌面 Integrator 页提供时间正则化。五种积分器共用 Sundman 方程与有界物理端点适配；科学插值、真实天气分段与任务滑行使用同一传播实现。默认关闭，开启后普通固定秒步长停止生效。该功能依据 STK 公开定义实现，尚无本机 STK 同配置结果。

## STK 语义与内部尺度

[STK Integrator](https://help.agi.com/stk/Content/hpop/hpopIntegrator.htm) 与 [Connect 命令](https://help.agi.com/stk/SubSystems/connectCmds/Content/cmd_HPOPIntegrator.htm) 定义 `dS = sqrt(mu) r^(-n) dt`，以 Exponent 和 Steps Per Orbit 设置正则化步长；二体问题中 n=1 对应偏近点角、n=2 对应真近点角。[官方比较](https://help.agi.com/stk/content/hpop/example_HPOPResults.htm) 包含 Gauss–Jackson 与时间正则化的组合。当前实现依据这些公开方程，不推定 STK 的内部控制器与所有合法范围。

`SundmanTransform` 取初始密切椭圆的半长轴 a0 和偏心率 e0，使用常数尺度 `q = S / a0^(3/2-n)`：

```text
T0 = sqrt(a0^3 / mu)
g(r) = dt/dq = T0 (r/a0)^n
Q0 = integral[0,2pi] (1-e0 cos(E))^(1-n) dE
fixed dq = Q0 / steps_per_orbit
```

n=1 时 Q0=2π；n=2 时 Q0=2π/sqrt(1-e0²)。其余指数以误差受控的自适应 Simpson 求积；n>2 使用真近点角的等价积分，避免窄近地点峰值。以 `(1-e)+2e sin²(E/2)` 等形式减少近抛物线输入的消减误差。归一化保持同一个初始轨道尺度，摄动不会在每步重置它。

有效范围为有限 `0<n<=10`、正 μ、非径向束缚初始轨道。非椭圆没有可用于 Steps Per Orbit 的周期，当前明确拒绝；不临时替换半长轴。官方 Connect 页面印出的指数不等式存在歧义，此范围尚不代表已核实 STK 的完整合法域。

## 方程与共用积分内核

RK4、RKF7(8)、RKV8(9)、Bulirsch–Stoer 使用七维状态 `(r,v,t)`：`r'=g v`、`v'=g a(t,r,v)`、`t'=g`。力评估收到真实秒与物理速度。内部一步积分器按状态维数和分量误差尺度模板化，普通时间 HPOP 复用相同系数与算法；正则化控制器可使用每步局部增量作补偿累加，避免把微小增量反复加到大的位置或时钟上。

Gauss–Jackson 使用混合系统 `(r,u,t)`，其中 `u=dr/dq`：

```text
r'' = g² a(t,r,u/g) + k u
k = n (r dot u) / |r|²
t' = g(r)
```

三维位置使用二次求和，真实时间使用同一方法的一次求和系数。`g(r)` 由位置直接求值；不另积分一个可能漂移的时钟导数，也不在步末投影状态。Pseudo Correction 保留最后一次力评估的物理摄动，加上校正状态的二体项，再更新全部坐标变换因子。Full Correction 重新调用完整力。

固定十八阶 BS 和 GJ 的十四至十八阶起步器使用 2/4/6/8/12/16/24/32/48 子步序列，并外推局部状态增量。该序列改善高阶外推的条件数；普通自适应 BS 保持 2/4/…/18。固定 BS 的算法来源为 `fixed18-v2`。GJ 起步到求和的衔接保留状态补偿、乘积与减法的舍入残差；重建预测/校正状态时也计入求和补偿。两种 GJ 算法来源升级为 `startup-*-v3`，项目结构仍为 v40 / OBJS31。

固定步数的 GJ 没有截断误差控制；校正收敛不等于轨道精度合格。高偏心率、尤其 n=2 时须检查步数加倍的结果。内核验收使用固定正则化端点，覆盖 e=0/.7/.98、正反向超过一圈、时变与速度相关摄动；完整范围、参考误差和命令见[验证协议](../validation/time_regularization_protocol.md)。

## 有界物理时间端点

`SundmanPropagation` 接收物理秒端点。调用力之前检查阶段时间是否位于当前连续力段起点与本次终点之间；拒绝的越界阶段不会访问外部数据。固定模式保留从 q=0 锚定的均匀网格，完整格始终使用同一个带符号 dq，避免两个圆整网格坐标相减造成 GJ 步长变化。

遇到越界阶段时，使用等价逆方程 `(r,v,q)` 在物理时间内积分：`dr/dt=v`、`dv/dt=a`、`dq/dt=1/g(r)`。它采用选定的 RK/BS；GJ 使用自身高阶 BS 起步器。边界子步不会跨过下一个 q 网格点，仍保留累积 q 相位。此时物理时间是自变量，所以可以准确停在输入的双精度端点；不把一个越界的积分时钟强改成目标值，也不投影轨道状态。边界内部前缀不输出，仅发布常规接受端点和请求终点。

GJ 在非均匀 q 段后重建历史，规则步的 r、dr/dq 直接连续传递给起步器，避免反复进行 u/g 再乘 g。真实时钟每步平移到局部零点；历史一次求和同步平移，全局秒另作补偿累加。物理速度与 dr/dq 转换保留乘除残差，供下一个起步或边界段使用。连续力发生跳变时，调用方结束旧段，再显式重置历史和力段起点；该适配器不自行发现天气或机动事件。

内部自适应模式同时控制位置、速度与局部时钟误差；时钟绝对尺度为 1e−11 s，避免容差随累计传播时间增大。每圈步数给出名义 q 上限，误差控制可以继续减小它；显式的物理 Min/Max Step 优先于该名义尺度。以起点 g 换算 q 仅作为提议，接受前检查真实时间增量；g 在步内变化导致越过物理范围时，以逆方程推进到约束给定的物理端点。误差要求再缩短该物理步时，最短尝试停在 Min Step；仍不满足便报错。位于最小 q 提议时也检查这一失败路径，避免同一步反复拒绝直到耗尽预算。

真正的力区间/输出边界可以比 Min Step 更近，采用区间内的截短子步；边界内部前缀不作为额外报告节点。固定模式不使用自适应 Min/Max Step 或误差控制。这套规则符合[STK API 的 Min/Max Step 使用时间量纲](https://help.agi.com/stkdevkit/Content/DocX/STKObjects~IAgVeStepSizeControl.html)，但名义 q 尺度与物理下限冲突时的优先级、逆方程切换和误差范数是本项目明确的实现，仍待 STK 同配置实测。每次调用与 GJ 起步、边界细分共享 200000 次尝试预算；失败或取消不返回部分状态，也不修改输入历史。

## 公共配置、历元与持久化

`time_regularization` 为启用开关，`regularization_exponent` 为指数，`steps_per_orbit` 为正的 int（至多 2147483647）。指数 1.5、每圈 120 步取自 STK 的公开示例，不宣称其为 STK 默认值。禁用时保留合法草稿，指数和步数不计入计算身份；启用时固定秒步长不计入身份。自适应 Min/Max Step 和容差只在相对误差模式生效。所有存储的草稿也必须通过参数校验。

Core 接收精确 int64 TAI 纳秒；内部以相对初态的秒积分，请求终点与输出网格直接保留原整数历元。直接状态查询每次从初态计算，保证查询顺序不会复用较长查询中越过当前终点的积分阶段。项目分析和任务查询则生成并缓存明确滑行区间的科学星历，后续插值不访问力数据。

天气跳变处使用原有单侧采样规则，结束旧力段后重建历史。跨报告时刻保留连续力段起点与 q 相位；因物理边界截短的逆方程前缀不覆盖下一次自适应 q 提议，后续完整步仍检查误差与物理范围，避免输出门限制造密集插值节点；机动后以新状态构造新的初始椭圆尺度。接受的浮点秒节点以原连续力段的导数作微小时间输运，使位置、速度与其整数纳秒标签一致，避免坐标舍入噪声被 Hermite 导数放大；此输运不改变积分历史或越界查询外部力。接受节点的整数纳秒若重合，保留精确输出/力边界，省略重复内部节点；不得覆盖初态或共享力边界。科学插值在每个连续力段内提供必要的支持点，不借用另一侧节点；固定输出仍严格遵守轨道页的整数时间网格。

项目 v40 / OBJS31 依次新增启用 u8、指数 f64、步数 u32；只接受当前格式，旧文件明确拒绝。独立固定样例以 `struct.pack` 组装，C++ 与 Python 必须精确重写原字节。Runtime 来源加入 `time=sundman-initial-ellipse-bounded-v1`、指数、每圈步数以及固定/相对误差的有效步长规则。保存参数不改变已捕获的分析快照。
