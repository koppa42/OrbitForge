# 太阳辐射压局部偏导

`srp_differential` 是 HPOP 变分计算的 C++ / SDK 基础接口，沿用 `evaluate_srp` 的同历元、同惯性轴几何与参数约定，返回名义光压、位置／速度状态块、所选太阳位置块、照明梯度及 `K=Cr×SRPArea/Mass` 参数偏导。K 的定义依据 [STK consider analysis](https://help.agi.com/stk/Content/hpop/hpop-covariance.htm)。它尚未接入完整 STM、协方差传播或 Python 协方差入口。

## 固定量与单位

固定接收历元、所选太阳地心向量 S、各遮挡体几何中心、半径、光压常数及 K，求对卫星位置 r 的偏导。另独立返回对 S 的偏导。加速度为 m/s²，位置／太阳 Jacobian 为 s⁻²，速度 Jacobian 为 s⁻¹，照明梯度为 m⁻¹，`d_a/d_K` 为 Pa；矩阵行为加速度分量，列为输入分量。

设 `d=|S−r|`、`n=(S−r)/d`、`Q=P_ref(d_ref/d)²`，照明比例为 f：

```text
a = −K Q f n
Jr = K Q [ f/d (I − 3nnᵀ) − n (grad_r f)ᵀ ]
Js = K Q [−f/d (I − 3nnᵀ) − n (grad_S f)ᵀ ]
Jv = 0                         （固定所选太阳向量时）
d_a/d_K = −Q f n
```

不以名义加速度除以 K，因此零 Cr、零 A/m 时仍保留参数敏感度；带符号 Cr 沿用现有契约。禁用模型返回零偏导，并沿用原入口的参数校验行为。

## 阴影面积变化

双锥使用现有均匀太阳视圆盘与至多十个球面遮挡圆盘的交并集。对每条暴露遮挡圆弧 `[a,b]`，圆心 `(x,y)` 和半径 R 的面积偏导为：

```text
∂A/∂x = R(sin b − sin a)
∂A/∂y = R(cos a − cos b)
∂A/∂R = R(b − a)
```

这是沿边界积分法向速度的面积变化率；交点移动的端点项相互抵消，固定单位太阳圆弧贡献为零。对三维位置到视圆盘的映射做六变量前向微分，再与面积变化率链式相乘；没有对生产力函数做数值差分。圆盘同心极限使用 `asin(t)/t` 的连续展开，避免角度方向的 0/0。物理中心与半径完全相同的重复遮挡体只计一次，排序不改变结果。

无阴影和远离接触的圆柱模型保持常数照明分支。圆柱接触、前向天体的深度门限接触、不同一阶变化的重合视圆盘明确抛出 `PropagationError`，当前接口不提供这些退化点的事件跳变矩阵。普通双锥外／内接触的照明一阶导数连续；重合边界具有不同法向速度时一般不存在唯一线性导数。

## 与传播器的边界

`nominal` 直接使用既有 `evaluate_srp`；名义力求值流程和项目格式 v40 / OBJS31 保持当前定义。普通轨迹不主动计算偏导。新增接口随 C++ SDK 导出，安装消费端实际调用；Python 的既有 SRP 配置、低层名义力和桌面界面继续复用相同名义模型。

STK 的太阳位置方法仍由 HPOP 在每个积分阶段解析，低层函数只消费已经选好的 S。[STK SRP 参数](https://help.agi.com/stk/Content/hpop/hpopSRP.htm)

- True 与地心视太阳在固定历元对卫星状态独立，可以直接使用上述状态块。
- 卫星视太阳同时依赖 r 与 v，未来装配时必须使用 `Jr + Js·∂S/∂r` 和 `Js·∂S/∂v`；不能把低层的零速度块当作该模式的完整导数。
- 完整星历链、阴影事件的变分处理、STM 与 consider 协方差尚待接入。名义传播已有的 Boundary Mitigation 不等于变分方程的事件处理。

独立 Orekit、mpmath 和 SciPy 对照、参考算法的数值限制及容限见[验证协议](../validation/srp_differential_protocol.md)。当前没有 STK 同配置实测数据，不据此宣称与其内部算法完全相同。
