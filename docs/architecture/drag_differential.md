# 阻力状态偏导与 consider 参数

`drag_differential(...)` 与 `evaluate_drag(...)` 接收同样的 ITRF 位置、相对共转大气的速度、太阳位置、UTC、阻力配置及天气快照。结果包含名义 `DragEvaluation`、`ForceDifferential`、密度位置梯度（kg/m⁴）和对 `D = Cd × Area/Mass` 的加速度偏导（Pa）。D 沿用 [STK consider analysis](https://help.agi.com/stk/Content/hpop/hpop-covariance.htm) 的定义，不是单独 Cd，也不是其倒数形式的弹道系数。

这是随 C++ SDK 安装的单历元计算基础。Python 和桌面仍通过现有入口使用修正后的名义阻力；完整 STM、协方差、参数传播和事件处理尚未接入，协方差页面不因此启用。

## 固定输入与方程

求导时固定 UTC、太阳矢量、天气、Cd 和面积质量比。太阳几何／视位置及两种大气各自滞后的天气仍由调用方提供，不在这里查询星历、读文件或重新取样天气。球形阻力无风场，所有分量均在 ITRF 轴下：

```text
s = |v|,  D = Cd A/m
 a = −ρ D s v / 2
Jr = −D s (v ⊗ ∇ρ) / 2
Jv = −ρ D (s I + v vᵀ/s) / 2
∂a/∂D = −ρ s v / 2
```

速度和 D 偏导解析求值。s=0 时两个状态块及 D 偏导为零。Cd=0 或 A/m=0 时状态块为零，但 D 偏导仍保留；不通过 `a/D` 求值。支持原配置允许的负 Cd。禁用阻力返回零结果，非法输入和非有限结果抛异常。

完整惯性状态转换需要 `r_B=R r_I`、`v_B=R v_I+R_dot r_I`，因此：

```text
Jr_I = Rᵀ (Jr_B R + Jv_B R_dot)
Jv_I = Rᵀ Jv_B R
```

不能只旋转两个 3×3 块而遗漏旋转率耦合。本接口本身返回 B=ITRF 的块；惯性变分方程装配仍待实现。

## 密度位置梯度

复用同一密度求值器，包含 JR、NRLMSISE-00、低空平滑混合、精确／径向近似高度、手动天气及原生日／历史 Ap。位置块中的密度梯度使用四阶差分：大地经纬度步长 1e−4 rad，高度步长 25 m；空间梯度通过 WGS84 曲率半径及高度梯度换算。经度扰动同时改变太阳时角。近似高度的径向椭球交点梯度解析计算，大地经纬度仍保持精确定义。

每个维度使用四个额外密度值。中心模板不能留在当前分段时使用单侧模板，必要时缩短步长，不跨越高度分段、经度切口或太阳时角切口。NRLMSISE 保留拟合公式中的近似角度转换常数，其切口不是严格周期连续；历史 Ap 公式还包含 `|latitude|`，使用当前半球分支，赤道取非负分支，与 Orekit 自动微分约定一致。

当前偏导入口对下列位置明确报错，名义阻力入口仍保持可用：

- 内部高度分段和混合端点附近 1e−5 m；包括 JR 100/125/200/500 km，NRLMSISE 温度节点和成分切换高度，以及所选混合边界。
- 经度或太阳时角切口附近 1e−12 rad。
- `|cos(latitude)| < 1e−8` 的经度奇点区域。

外侧有效高度端点使用单侧导数。这些限制属于尚待完成的变分事件／极点处理，不能把局部 Jacobian 直接当作跨边界的完整协方差解。四阶差分及回归阈值不是对任意极端天气的精度保证。

## JR 高空数值稳定性

原标量公式使用 `(T∞−T)/(T∞−Tx)` 及 `(T∞−T)/(T∞−T500)`。高空 T 接近 T∞，相减会损失有效数字，部分低太阳活动、2500 km 输入甚至得到零密度。

实现保留原有常数和分段，只将这些比值的幂改为直接从温度指数求 `exp(γ E_h)` 与 `exp(γ(E_h−E_500))`。温度仍由原公式计算；不再把已舍入的温度差用于密度比值。采用保留原相减公式的 80/100 位 GMAT 方程转写独立核对；两种精度舍入到 binary64 完全一致。既有 576 组输入及密度容限保留，高空期望值改用高精度参考。

来源、可复现生成器、固定散列和验收界限见[阻力偏导验证](../validation/drag_differential_protocol.md)。
